# siteday.suhi.app

Landing page for SiteDay, construction site progress reporting for contractors and supervision consultants. A Suhi app.

A single static `index.html` (inline CSS and JS, no build step) plus images in `assets/`. Served by GitHub Pages from `main` at the repo root; the custom domain is set in `CNAME`.

App screenshots in `assets/shots/` are taken from the SiteDay iOS app and compressed to JPEG. To preview locally:

```bash
python3 -m http.server 8000
```
